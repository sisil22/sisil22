## 🚀 Featured Projects

### 📦 [Brazilian E-Commerce Analytics (Olist)](https://github.com/sisil22/brazilian-ecommerce-analytics)
End-to-end SQL-to-dashboard analytics project on 100,000+ customer transactions.  
Uncovered that **97% of customers were one-time buyers** and delivered strategic recommendations for loyalty programs and logistics optimization.  
`SQL` `Cohort Analysis` `Dashboard` `Business Analytics`

---

### 💳 [Credit Card Fraud Detection](https://github.com/sisil22/credit-card-fraud-detection)
ML-based fraud detection pipeline on 284,000+ transactions.  
Improved fraud detection **F1-Score from 23% → 83%** using SMOTE + Random Forest.  
Estimated protection of **82.7% of financial assets** from potential fraud.  
`Python` `Scikit-learn` `SMOTE` `Random Forest` `SHAP`
